# 이세형 · Mechanical Engineering Portfolio

**CFD · 열유동 해석 · 데이터 기반 온도 예측 · 해석 자동화**

안녕하세요. 서강대학교 기계공학 석사과정에서 열유동 해석과 데이터 기반 예측을 연구하는 이세형입니다. 가열로 내부의 연소·복사 열전달을 해석하고, 여러 작동조건을 비교하는 데 필요한 계산과 데이터 처리 과정을 개선해 왔습니다.

이 포트폴리오는 연구 결과와 함께 제가 문제를 정의하고, 계산 방법을 검토하고, 팀원들과 제작물을 개선한 과정을 정리한 기록입니다.

![POD와 RBF로 예측한 소재 온도분포와 CFD 결과의 비교](assets/rom-comparison-max.png)

*가열로 소재의 온도분포 비교. 왼쪽은 CFD 데이터, 오른쪽은 POD+RBF 예측이며, 테스트 케이스 중 RMSE가 가장 큰 사례(6.38 K)입니다. 그림의 범례는 원본을 유지했습니다. [평가 조건과 결과 보기](projects/furnace-rom/README.md)*

## 대표 프로젝트

| 프로젝트 | 해결하려던 문제 | 주요 결과 및 기록 |
|---|---|---|
| [가열로 CFD 해석 개선](projects/furnace-cfd/README.md) | 여러 조건을 계산하기에 큰 계산량과 높은 잔차 | 32코어·2,000회 반복 기준 **4시간 → 50분** |
| [POD+RBF 온도분포 예측](projects/furnace-rom/README.md) | 조건마다 수 시간이 걸리는 CFD 계산 | 테스트 평균 RMSE **2.89 K**, 학습 후 예측 **1초 미만** |
| [Fluent 반복 해석 자동화](projects/fluent-automation/README.md) | 조건 변경·실행·추출을 매번 수동으로 수행 | Excel 조건표를 읽고 최대 **3개 케이스 동시 실행**, CSV·로그 저장 |
| [HBM 압착 유동의 기초 검증](projects/hbm-squeeze-flow/README.md) | 복잡한 모델을 적용하기 전 수치해석 검증 | 단순화한 조건의 두 시점에서 압력 상대오차 **0.337%, 0.692%** |

> 계산시간 개선, CFD 대비 예측 오차, 해석해 대비 압력 오차는 서로 다른 평가입니다. 각 수치의 조건과 적용 범위는 프로젝트별 페이지에 기재했습니다.

## 제가 맡은 일

- 기존 가열로 해석 모델을 인계받아 격자 구성을 변경하고, 계산시간·잔차·온도분포를 비교했습니다.
- 작동조건별 데이터를 생성하는 Python 자동화 흐름을 구현했습니다. 코드 작성에는 생성형 AI를 활용했습니다.
- 데이터 추출 위치와 시각화 방식, POD 및 여러 예측 방법을 검토하고 테스트 결과를 비교했습니다.
- 제작 프로젝트에서는 팀원들과 아이디어를 시험하고, 부품의 실제 동작에 맞춰 설계를 수정했습니다.
